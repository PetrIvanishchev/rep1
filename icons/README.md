# Иконки

Страница `akkaunt.html` использует пиксельные иконки (квадратные пиксели, без сглаживания).

- **Pixelarticons** (Gerrit Halfmann, лицензия MIT, https://github.com/halfmage/pixelarticons): сердечко, деньги, книга, собака, лист (растение), карандаш, мусорка, крестик (без стикера), а также 20 случайных иконок аккаунта: звезда, луна, солнце, облако, музыка, подарок, корона, ключ, флаг, колокол, камера, кубок, торт, огонь, якорь, шарик, пришелец, жук, замок, искры.
- **Pixel Icon** (HackerNoon, лицензия CC BY 4.0, https://github.com/hackernoon/pixel-icon-library): самолёт (`pixel:plane`).
- **Нарисованы вручную по клеточкам:** единорог, семья, попкорн (в наборах пиксельных иконок их нет).
- Иконки получены через https://api.iconify.design/.

`unicorn-head.svg` (Lucide Lab, лицензия ISC) лежит здесь с прошлой версии страницы и сейчас не используется.
