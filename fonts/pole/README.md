# Шрифты для страницы `akkaunt.html`

Все шрифты открытые (лицензия SIL Open Font License 1.1), с кириллицей. Источники: репозиторий https://github.com/google/fonts (папка `ofl/`) и https://github.com/googlefonts/caveat. Лицензии лежат рядом (`OFL-*.txt`).

Четыре датчика шрифта: **О**т руки, **К**аллиграфический, **Ш**ирокий, **Оф**ициальный. Шестнадцать сочетаний, ближайший шрифт отмечен словом «ближайший».

| Сочетание | Шрифт |
| --- | --- |
| нет | Press Start 2P (пиксельный) |
| от руки | Caveat |
| каллиграфический | Marck Script |
| от руки + каллиграфический | Pacifico |
| широкий | Russo One |
| от руки + широкий | Comfortaa |
| каллиграфический + широкий | Playfair Display |
| от руки + каллиграфический + широкий | Lobster |
| официальный | PT Serif |
| от руки + официальный | Bad Script |
| каллиграфический + официальный | Philosopher |
| от руки + каллиграфический + официальный | Marck Script (ближайший) |
| широкий + официальный | Russo One (ближайший) |
| от руки + широкий + официальный | Comfortaa (ближайший) |
| каллиграфический + широкий + официальный | Playfair Display (ближайший) |
| все четыре | Yeseva One |

`PressStart2P-Regular.ttf` — пиксельный шрифт страницы и плашки по умолчанию (https://github.com/google/fonts/tree/main/ofl/pressstart2p), кириллица 64 из 64.
