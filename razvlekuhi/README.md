# Развлекухи

Сюда записывается информация по следующему сайту: цель, задание, предикаты, заметки.

## Сайт 1. Расписание на неделю

- Страница: [`index.html`](./index.html)
- Задание: [`zadanie.md`](./zadanie.md)
- Переключатели «Шрифт для дислексии» и «Режим для телефона» (ключи `dys` и `phone` в `localStorage`).
- События сохраняются в браузере (`localStorage`), JavaScript нужен для кнопки «+» и формы.
- Шрифт «от руки»: Caveat (лицензия SIL OFL, `fonts/OFL-Caveat.txt`). Источник: https://github.com/googlefonts/caveat
- Режим для дислексии: шрифт OpenDyslexic (лицензия SIL OFL, `fonts/OFL-OpenDyslexic.txt`). Источник: https://github.com/antijingoist/opendyslexic. Переключатель запоминает выбор в браузере тем же ключом `dys`, что и сайт истории кино.
