# История поломок и реакция проверки

Дата: 2026-11-28. Опыт: нарочно сломать вёрстку двух страниц и посмотреть, заметит ли `./check.sh`.
Правки были только в локальных файлах, без коммита и деплоя. Обе страницы возвращены к закоммиченной версии через `git checkout -- <файл>`.

## Поломка 1. `index.html` (главная)

Что изменили в CSS (3 правки):

| Правило | Было | Стало | Ожидаемый эффект |
| :-- | :-- | :-- | :-- |
| `main` | `max-width: 34rem` | `max-width: 6rem` | весь текст сжат в узкую колонку |
| `.box` | без позиционирования | `position: absolute; top: 0; left: 0` | блок «Твой следующий ход» наползает на заголовок |
| `th, td` | `text-align: left; padding: 8px 10px` | `text-align: right; padding: 0` | ячейки таблицы слипаются |

Что показал `./check.sh`: **ЗЕЛЁНОЕ**. ДА 31, НЕТ 0, глазами 4.

Почему проверка не заметила:
- Проверки главной смотрят на содержимое: 30 строк в таблице, оценки по убыванию, без повторов, сообщение при ошибке сети, заголовок и ссылка на «Историю кино».
- Предикат «страница читается на телефоне (375px)» ищет только прокрутку вбок у страницы. Узкая колонка её не создаёт, поэтому предикат остался «ДА».
- Внешний вид главной скрипт не оценивает.

Вывод: пробел в проверке касается только вёрстки главной.

## Поломка 2. `istoriya.html` (история кино)

Что изменили в CSS (3 правки):

| Правило | Было | Стало | Ожидаемый эффект |
| :-- | :-- | :-- | :-- |
| `main` | `max-width: 38rem; width: 100%` | добавлено `display: flex; flex-direction: row-reverse; flex-wrap: wrap` | порядок блоков перевёрнут |
| `.era` | `margin: 28px 4px; transform: rotate(-1deg)` | `margin: -20px 4px; transform: rotate(-12deg)` | блоки сильно наклонены и наползают друг на друга |
| `p` | `margin: 0 0 1rem` | добавлено `color: var(--paper)` | текст абзацев сливается с бумагой |

Что показал `./check.sh`: **КРАСНОЕ**. ДА 30, НЕТ 1, глазами 4.

Что покраснело (единственная строка с «НЕТ»):
`История, уточн. 2.2: каждая эра в «вырезке»: наклон не больше 2°, заголовок крупнее текста`

Почему проверка сработала только частично:
- Заметен был наклон `.era`: 12° больше допустимых 2°.
- Слитый с фоном текст пропущен. Проверка контраста слов (4,5) есть только для слов заголовков, а не для абзацев.
- Перевёрнутый порядок блоков пропущен: вид страницы оценивается «глазами» (принято владелицей 2026-11-21).

## Что видно из опыта

- Скрипт хорошо проверяет то, что можно посчитать: числа, ссылки, наличие элементов, цифры наклона.
- Он слаб там, где нужен взгляд: наложение блоков, порядок на странице, читаемость текста абзацев.
- Пункты «ГЛАЗАМИ» не проверяются машиной вовсе. Здесь ответственность на приёмщике (ОТК): открыть страницу в браузере.
